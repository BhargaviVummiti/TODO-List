#To-Do-List
-----------
Built a To-Do List Web Application using HTML, CSS, and JavaScript to help users manage daily tasks efficiently.
This project allows users to add, edit, delete, and mark tasks as complete.
It also uses Local Storage to save tasks so they remain even after refreshing or closing the browser.
The design is simple, responsive, and perfect for beginners to practice DOM manipulation and event handling in JavaScript.

Features:-
---------
1.Add new tasks easily

2.Mark tasks as completed

3.Delete tasks from the list

4.Saves all tasks in browser’s local storage

5.Responsive design for all screen sizes

6.Clean and user-friendly interface

Technologies Used:-
------------------

HTML – Structure of the web app
CSS – Styling, layout, and responsive design
JavaScript – Functionality for adding, editing, deleting, and saving tasks

How to Run:-
----------
1.Go to To-Do List project on GitHub:

2.Download all the files as a ZIP.

3.Extract the downloaded folder.

4.Open the index.html file in any modern web browser (Chrome, Firefox, Edge, Safari).

5.Start adding your daily tasks and enjoy managing them easily!
